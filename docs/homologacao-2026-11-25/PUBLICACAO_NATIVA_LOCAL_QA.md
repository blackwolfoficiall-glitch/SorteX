- Para reproduzir, executar o smoke no stack local descartável com os dois organizadores sintéticos previstos em `homologacao-web-ios.yml`. Para incluir os dois navegadores, instalar localmente Chromium e WebKit do Playwright na workspace Web e definir `SORTEX_PARITY_WEB_RENDER=yes`. O tráfego do navegador fica limitado à URL local do site.

**Limite:** prova de cliente HTTP e site renderizado em navegadores; não de interface nativa autenticada, câmera/seletor no iPhone, instalação física ou atualização da API hospedada. A execução não muda o placar de jornadas completas do app nem de paridade integral.
