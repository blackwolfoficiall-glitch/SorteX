## Etapas separadas

1. O workflow manual usa o ambiente protegido `sortex-web-ios-qa` e a chave Neon já restrita ao projeto. Não imprime a chave, não lê valores do ambiente e não cria/revela credenciais de storage. O modo padrão `preflight` (único permitido em push, apenas se este arquivo de workflow mudar na branch candidata) faz apenas GET do projeto Free, branch, estado/endpoint do storage, lista de buckets e saúde da API QA. Um plano elegível não garante cota disponível; confirme saldo de invocações e storage. Não contrate upgrade.
2. **Só com autorização separada** para função e um único objeto sintético: selecione `execute`, confirme literalmente `sortex-qa-media` e habilite `SORTEX_QA_STORAGE_SMOKE=yes` só no GitHub protegido, com a branch candidata como única permitida. O primeiro deploy precisa do ZIP. A função `sortexqastoragesmoke` é separada, inédita, sem uso do banco, nenhuma credencial AWS definida manualmente, sem domínio personalizado e sem trigger. O workflow recusa qualquer outra função em vez de sobrescrevê-la.
3. A URL HTTPS é alcançável publicamente, mas o handler responde 404 sem autorização, sem CORS, sem diagnóstico e sem dados. Só o runner conhece o token de uso curto (até oito minutos); no deployment fica somente seu hash. Primeiro confirme recusa anônima do endpoint de smoke e, com autorização, **HeadBucket pelo adaptador existente com credenciais injetadas**. A verificação assinada da chave nova deve retornar 404 antes de gravar, sem listar ou tocar objetos anteriores. A execução cria um PNG sintético de 69 bytes em chave UUID reservada com `If-None-Match: *`. Um segundo cliente lê o objeto, confere bytes/SHA-256 e confirma que o GET sem assinatura no S3 recebe 401/403, não só 404. O SDK na função de diagnóstico também não repete a tentativa. Não repita se o resultado de escrever ficar ambíguo. Não há impressão de chave de objeto, URL assinada ou segredo.
4. O workflow reconfirma que a API principal segue na mesma revisão, com storage desabilitado. O PNG permanece no bucket; não há deleção automática. O handler recusa chamadas após a expiração e o script recusa uma função de diagnóstico existente. Remoção/renovação é uma ação separada. A prova não valida restauração do bucket, mídia do app nem UI em iPhone.
5. `workflow_dispatch` exige que o workflow esteja registrado na branch padrão do GitHub. Pode não ser possível disparar pela branch de homologação isolada. **Não altere `main` para contornar isso.** O ZIP pode ser preparado e inspecionado offline para um caminho protegido já autorizado, com as mesmas condições. Não execute os deployers existentes para tentar esta prova.

## Se for autorizado habilitar a aplicação depois

- Reconfirme o smoke, bucket privado, projeto/branch, SHA, ID ativo/atual e nomes do ambiente sem ler valores. Não aceite overrides `AWS_*`, `NEON_BRANCH_ID` ou `NEON_FUNCTION_HOST_SUFFIX`: mascaram a injeção de runtime.
- A atualização **config-only** usa multipart do Neon no mesmo `sortexqa`: omita ZIP, preserve o código e `APP_VERSION`, altere só `STORAGE_DRIVER=neon-s3`, `STORAGE_BUCKET=sortex-qa-media` e `UPLOADS_DISABLED=false`. Não passar credencial, JWT, banco ou endpoint AWS. Confirme o novo deployment, a mesma revisão da API e `storage: up` (o próprio endpoint faz `HeadBucket`). Compare nomes privados, não valores. O deployer de código atual exige `storage: disabled` e não deve ser reutilizado para ativar ou após ativar.
- Antes de reversão autorizada, verifique se o mesmo novo ID está ativo e o SHA não mudou, sem deploy concorrente. Novo deploy config-only retornando `UPLOADS_DISABLED=true` e os valores anteriores verificados para os outros dois campos. Se não existiam, use string vazia para removê-los conforme o merge do Neon. Confirme `storage: disabled`, mesmo SHA e banco pronto. Não exclua objetos, funções ou buckets nesta operação.
- A aplicação ainda precisa demonstrar upload, leitura autorizada, isolamento, retenção após nova instância e restauração, com dados exclusivamente sintéticos. Sem storage durável, mantenha os uploads desligados e não use `/tmp` como volume.
